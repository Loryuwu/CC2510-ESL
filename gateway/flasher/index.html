PriceTag Gateway – Flasher

ESP32-S3-Gateway (OEPL-Shim) per USB direkt aus dem Browser flashen.

⚠️ Dieser Browser kann kein Web Serial – bitte Chrome oder Edge (Desktop) nutzen. ⚠️ Nur über HTTPS oder localhost nutzbar (Web Serial braucht sicheren Kontext).
Die Firmware-Dateien (bootloader.bin, partitions.bin, boot_app0.bin, firmware.bin) sind nicht im Repo (Build-Artefakte). Nach dem lokalen pio run neben diese Seite kopieren – siehe README.
  1. Gateway lokal bauen: cd gateway/gateway_oepl_shim && pio run
  2. Die vier .bin in diesen Ordner kopieren (Befehle im README).
  3. Ordner über HTTPS oder localhost ausliefern (z. B. python -m http.server → http://localhost:8000/).
  4. ESP32-S3 per USB anstecken, Install klicken, Port wählen, flashen.
